# Website Development Rules

## Design

Build modern, polished and visually distinctive websites.

Use the available Codex skills when relevant, especially:
- emil-design-eng
- prototype
- apple-design
- brandkit
- pick-ui-library

Prioritize:
- strong visual hierarchy
- clean spacing
- excellent typography
- responsive layouts
- subtle micro-interactions
- accessibility
- performance

Avoid generic-looking templates and unnecessary visual effects.

## Animation

Anime.js is installed in this project.

Use Anime.js for meaningful UI animation and micro-interactions.

Relevant skills:
- animate
- animation-vocabulary
- find-animation-opportunities
- improve-animations
- review-animations

Prefer:
- subtle entrance animations
- staggered text/content reveals
- smooth hover interactions
- scroll-triggered animations where appropriate
- purposeful micro-interactions

Avoid:
- excessive animation
- distracting effects
- animation that hurts usability or performance

## Code

Before making major changes:
1. Inspect the existing project structure.
2. Understand the current implementation.
3. Reuse existing components where possible.
4. Keep the code clean and maintainable.
5. Test the result after changes.

Use Anime.js through the project's installed dependency rather than adding unnecessary animation libraries.
